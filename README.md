# Analisis-Perbandingan-Performa-Model-CNN-MLP-dan-CNN-MLP-pada-Klasifikasi-Produk-Fashion
Proyek klasifikasi produk fashion menggunakan CNN (MobileNetV2), MLP, dan model Fusion (CNN+MLP) dengan memanfaatkan data citra dan metadata produk untuk mengklasifikasikan 20 kategori fashion.

Dataset yang digunakan berasal dari kaggle dengan link berikut: https://www.kaggle.com/datasets/sawkumar/fashion-datasets/data
